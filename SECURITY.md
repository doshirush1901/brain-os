# Security

## Reporting

Email security concerns to the maintainers listed on the GitHub org profile.  
Do not open public issues for unpatched vulnerabilities.

## Scope

- **brain-os:** public skeleton; synthetic demo data only.
- **Your fork:** you are responsible for `.env`, Gmail OAuth, and production data paths (`BRAIN_DATA_DIR`).

## Secrets

Never commit `.env`, OAuth tokens, or license keys (`bos_live_*`).
